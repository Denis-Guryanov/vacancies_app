# Приложение для поиска вакансий в сайта HH.pu

## Установка
1. Установите репозиторий командой:
```
git clone https://github.com/Denis-Guryanov/vacancies_app.git
```
2. Установите зависимости используемые в данном репозитории:
```
poetry install
```

## Функционал
Проект запрашивает вакансии с сайта HH.ru и сохраняет их в формате JSON

* Поиск вакансий по названию
* Выведение топа вакансий по заработной плате
* Поиск вакансий по ключевому слову в описании
